# Orbit

Salas para compartilhar tela com amigos (WebRTC + WebSocket).

## Rodar localmente
```
npm install
npm start
```
Abra http://localhost:3000

## Hospedar (Render)
- Build Command: `npm install`
- Start Command: `npm start`
- Variáveis opcionais para TURN: `TURN_URL`, `TURN_USER`, `TURN_PASS`
